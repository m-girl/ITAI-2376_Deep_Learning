# ITAI Midterm Project: Creating Images with Diffusion Models

## Overview

This repository contains the completed work for the ITAI Midterm Assignment: **Creating Images with Diffusion Models**.

The objective of this project was to implement, train, evaluate, and analyze a diffusion-based image generation model using a U-Net architecture. The project explores the fundamental concepts behind modern generative AI systems such as Stable Diffusion, DALL-E, and Midjourney.

The model learns to generate images by gradually adding noise to training images and then learning how to reverse that process through denoising.

## Project Components

### 1. Dataset Preparation

The dataset pipeline includes:

- Dataset loading
- Image preprocessing
- Normalization
- Train-validation splitting
- DataLoader creation

### 2. U-Net Architecture

The diffusion model utilizes a U-Net neural network containing:

- Encoder blocks
- Decoder blocks
- Skip connections
- GELU activation functions
- Time conditioning
- Class conditioning

Skip connections preserve high-resolution spatial information and improve reconstruction quality throughout the denoising process.

### 3. Forward Diffusion Process

The forward diffusion process gradually corrupts images by adding Gaussian noise over a sequence of timesteps.

Training samples are generated by:

1. Selecting a clean image
2. Selecting a random timestep
3. Applying the corresponding noise level
4. Recording the actual noise added
5. Training the U-Net to predict that noise

### 4. Reverse Diffusion Process

During generation:

1. Start with pure random noise
2. Predict the noise present at each timestep
3. Remove a portion of the predicted noise
4. Repeat iteratively until a clean image emerges

This process enables the creation of completely new images from noise.
